## 本当に詰まっていた場所は2つあった

### ① 金額を15倍で記録していた（Edge Functionのデプロイではなかった）
`voice_usage_log` は `RATE_PER_SECOND_USD = 0.02`（＝$1.20/分）で記録していた。
xAIの公式単価は **$0.08/分**。**15倍**。
実測 280秒 → 記録 $5.60／正しくは **$0.3733**。
上限$4.50に当たっていたのは、使いすぎではなく**帳簿の桁**だった。

直し方：Lovable の **クラウド → SQL editor**（Supabaseのダッシュボードに入らずに叩ける口）で
```sql
update voice_usage_log set estimated_cost_usd = round((duration_seconds*0.08/60.0)::numeric,6) where status='completed';
```
※ 直す前の全行は `status/1301_voice_usage_backup.json` に控えた。

### ② Lovableのビルドが落ちていて「公開」自体が塞がっていた
9/27 の全コミットが「ビルドに失敗しました／公開がブロックされています」。
＝ **mainに入っている直しが1つも本番に出ていなかった**（9/24の `e56d573` が出ていないのもこれ）。
Lovableの「ビルドを修正」（クレジット消費なし）→ ビルドが通り、16:24 と 16:46 に公開。
