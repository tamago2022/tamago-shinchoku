## ★原因は1ページの事故ではない。選び方が2か所とも「門が無い」

### ① 「この流れで、もう一本」＝ `src/lib/shelfPicks.ts` の `getAutoShelfPicks()`

**いま何で選んでいるか（実装を読んだ結果）**

```
その曲が置かれている棚を最大4つ取る → 各棚から1曲ずつ取る
```

★**それだけ。** 取った1曲が、元の曲と何の関係があるかを**一度も見ていない。**
同じ棚に入っているというだけで「この流れで」と名乗って出ている。

文脈チェック（`matchesEraContext` → 年代・表記圏・`sharesMusicalContext`）は書いてある。
**しかし `usedEraFallback === true` のときしか動かない。**
つまり「その曲がどの棚にも無くて、年代で棚を借りてきたとき」だけ。
**普通に棚に入っている曲（＝大多数）は、門を1つも通らずに出ている。**

実測（Pomplamoose「September」）：

| 出ていた札 | 棚 | 関係 |
|---|---|---|
| Nothing Compares 2 U / Sinéad O'Connor | 名カバーの棚 | 無し |
| Rock the Space Freak / Bill McClintock | マッシュアップ横丁（実験中） | 無し |

**直し方（1か所）**：`matchesEraContext` の呼び出しを `usedEraFallback` の中から出し、
`takeFrom()` の全経路で必ず通す。門を1つにして、通らない札は**出さない**（枚数合わせで埋めない）。
→ 「この流れで」が2枚しか出ないページが増えるが、**根拠の無い札が出ているより良い。**

### ② 「同じ時代の曲」＝ `src/pages/cover-guide.tsx`

```ts
if (songYear && Math.abs(p.year - songYear) > 10) return false;
```

★**`songYear &&` が効いている。** その曲に `year` が無いと、年差チェックが**丸ごと素通りする。**
`year` が無い曲は 26,529曲。だから 107,940枚が無検査で出ている。

実測（Pomplamoose「September」＝2011）：
赤い公園「yumeutsutsu」**2020年** が「Pomplamoose と同じ時代の曲」として出ていた。
（※ページの曲データ自体には `year: 2011` が入っているが、このセクションに渡る `songYear` が
 undefined のまま呼ばれている経路がある。まずゲートを「年が無ければ出さない」に倒せば、この穴は塞がる。）

**直し方（1か所）**：
```ts
const ERA_YEARS = 15;              // ← 「同じ時代」の定義はここ1か所だけ
if (!songYear) return false;       // ← 年が無いなら、このセクションを出さない
if (Math.abs(p.year - songYear) > ERA_YEARS) return false;
```
★**年が無い＝判定できない＝出さない。** 素通りさせない。
（年がある場合の年差超えは実測0件。つまり**穴はこの素通りだけ**。）

## ★繋ぎの決まり（たまごさん 2026-09-24）

> 「同じ曲名だからってカバーとは限らないからね。繋ぐんであるならば、ちゃんと裏取って繋いでよ。」
> 「ただ名前が一緒だから繋いだみたいな間違いは、本当にAI臭いからさ。
> 『脊髄反射で調べもしないで繋いでるんだな』っていうのが、分かる人には分かっちゃうから。」

**証拠にならないもの（弾く）**
- 曲名が一致しただけ … 「September」「花」「Volare」。棚の中にも「花」が ORANGE RANGE と Fujii Kaze で別々に在る。
- アーティスト名が一致しただけ … akikoの棚に矢野顕子／NON STYLEにHarry Styles の前例。
- 年が近いだけ … それは「同じ時代」の根拠であって、カバーの根拠ではない。

**証拠になるもの（出典URLとセットで1つ以上）**
`credit`（作詞作曲クレジットが同じ）／`official`（公式がカバーと書いている）／
`jasrac`（同一作品として登録）／`shiryou`（信頼できる資料に記載）

**取れないなら繋がない。** 間違ったまま出ているより、無い方がマシ。

### Pomplamoose「September」について

曲のidは `september-earth-wind-and-fire`、紹介文には「原曲の多幸感」と書いてある。
EW&F「September」（1978）は棚に在る（id: `earth-wind-fire:september`）。
**だが `originalRef` が入っていないので ★原曲 リンクが出ない。**

★**それでも、この便では繋いでいない。** 内部のid命名と自作の紹介文は出典ではない。
**裏取り待ちの895件の1つとして関所に積んである。** 出典が取れたら繋ぐ。取れなければ繋がない。
