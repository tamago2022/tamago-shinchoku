## なぜ溜まっていたのか（2つとも「書いてあるのに効いていない」形だった）

### ① 一番残るものが、網に一度も掛かっていなかった

`tools/orphan_reaper.py` のホワイトリストは
`bun run build` / `npm run build` / `next build` しか見ていない。
実際に **68分** 居残って **701MB** まで膨らんでいたのは
`node ./node_modules/.bin/vite build`（joy-relief-station・素のvite）とその
`esbuild --service` の子。**素のviteは1文字も書かれていなかった。**

### ② 居残りは「1本が長い」形ではなく「短いものが何本も重なる」形だった

`tools/top_status.py` の末尾は、心臓が**15秒ごとに読み直して**十数本の python3 を
Popen する。Macが重いと前の周の1本が終わる前に次の周が来るので、同じスクリプトが重なる。
実測：同時刻に ppid=1 の Python が15本、うち13本が同じ親の子で、どれも数秒前に生まれていた。
**重なるほど重くなり、重いほど重なる（正のフィードバック）。**
これまでの対策は全部「溜まったものを後で刈る」側で、元栓は開いたままだった。
