## 3. 作った仕組み：閉じずに終われない（Stopフックの関所）

`tools/stop_kanmon/tab_kanmon.mjs`（新規）。`.claude/settings.json` の **Stop / SubagentStop** に足した。

### 何をしているか
**枚数を数えにいかない。**セッションの記録（transcript）を読んで、道具の呼び出し回数を数える。
OSには一切触らないので、**許可ダイアログは出ない。0円。**

| 数える | 道具 |
|---|---|
| 開いた | `tabs_create_mcp` ／ `navigate`（**tabIdを渡さない呼び方は1枚勝手に作る**）／ `preview_start` ／ 内蔵の `tabs_create` |
| 閉じた | `tabs_close_mcp` ／ 内蔵の `tabs_close` |

**開いた数 > 閉じた数 → exit 2 で終了を拒否。** `browser_batch` の中に入れた呼び出しも数える。
**口で「閉じました」と言ってもごまかせない。本当に閉じる道具を呼ぶまで終われない。**

### 人質にしない（憲法）
- transcript が読めない／形が違う → 黙って通す（exit 0）
- 3回止めても合わなければ、台帳に残して通す（無限ループを作らない）。そのとき
  「報告に閉じる前→後を書け」という一言を渡す。

### 叩いて確かめた（実測4通り）

| 試したこと | 期待 | 返り |
|---|---|---|
| 開いた2・閉じた1（`navigate` の tabId 無しを1枚と数えるか） | 拒否 | **exit 2**「開いた 2枚／閉じた 1枚／残り 1枚」＋URL表示 |
| 開いた1・閉じた1 | 通す | **exit 0** |
| transcript が無い | 通す（人質にしない） | **exit 0** |
| `browser_batch` の中に create 1・close 1 | 通す | **exit 0**（中身を数えられている） |
| 同じセッションで4回止めようとする | 3回で諦めて通す | **exit 2 / 2 / 2 / 0** |

★試験で台帳(`status/1154_stop_kanmon.jsonl`)に入れた `TEST*` の行は**全部消した**（残り5行・TEST行0件）。
