## 4. ついでに ― 産地の誤りを機械でまとめて直した

1023番は2件を**1件ずつ手で**直した。だが原因は2件に固有ではない。
**「その国の音楽の話」を「その人の出自」と読み違えている**という**1つの型**だった。

機械で136件の候補を洗い出して（複数国ヒット24／弱い語53／決め手が概要の後半59）、
語を消すのではなく**読み方のほうを直した。**

| 直した規則 | 中身 |
|---|---|
| 「◯◯の」は、うしろに**人を指す語**が来て初めて出自 | ○「イギリスのバンド」 ×「ジャマイカのルーツ」「日本の音楽シーン」 |
| 裸の国名・ジャンル名は、**出自マーカー**が近くにあるときだけ | ×「K-POPなど多様なジャンルをルーツに持つ」 |
| **仕事の話**（放送局・レーベル・チャート）は出自ではない | ×「米国のカートゥーン・ネットワークで放送された」 |
| **生まれた場所は国籍とは限らない**。根拠に強さを付けた | 「ドイツ生まれ…アメリカのベーシスト」→ アメリカ |
| 「◯◯・◯◯出身／生まれ」を**国名の一覧から機械で作った** | 1国ずつ足すのをやめた＝足し忘れが構造的に起きない |
| 「◯◯が生んだ」「◯◯を代表する」も出自の名乗り | 「フランスが生んだシャンソン歌手」 |

**結果（1,297組 → 1,331組）**

| | 件数 | 例 |
|---|---|---|
| 誤り → **空欄**に倒した | **29組** | eill（K-POPで韓国に）／Masego（ジャマイカのルーツで）／PUFFY（米国の放送局で）／Khruangbin（タイのファンクで） |
| 誤った国 → **正しい国**に直った | **7組** | 9m88 日本→**台湾**／Kula Shaker インド→**イギリス**／atif-aslam インド→**パキスタン**／ash アイルランド→**イギリス**（北アイルランド）ほか |
| 空欄 → **新たに付いた** | **63組** | John Lennon／Rosalía／Tyla／UB40／Wet Leg／Fela Kuti ほか |

★**空欄は嘘より良い。**29組は「分からない」に倒した（関所の掟）。
