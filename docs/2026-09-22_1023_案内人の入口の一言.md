# 1023番 申し送り ― 案内人の「入口の一言」（2026-09-22）

## たまごさんの注文と、そのむずかしさ

> 「短く受け答えしてるのはすごくいいんだけど、もうちょっとだけ説明が欲しい。ちょっとシンプルすぎる」

前に、正反対のことも言われている：

> 「喋りすぎはやっぱ減点。うざいから、適当に短くていい。1行でいい」

**矛盾していない。「長くしろ」ではなく「中身を良くしろ」。**
だから今回は**行数を1行も増やしていない。**増やしたのは札の中の1行だけ（これはもともと空いていた場所）。

---

## 1. 札に「入口の一言」を刷った（ここが本体）

これまで札に出ていたのは `アーティスト名　1979年` だけだった。
**誰が見ても同じ＝「あなた」が無い。**これが「シンプルすぎる」の正体。

そこに、**棚に書いてあることだけ**から作った1行を足した。

| 出す順 | 出る言葉 | どこから取ったか |
|---|---|---|
| ① | これが今日の冒険の1枚 | 安心4：冒険1のうちの冒険札 |
| ①' | やさしい告白。／踊りたい夜。 | **人が書いた、その曲の一文**（棚の `n/` 9,527本） |
| ② | ロシアの棚から／台湾の棚から | 産地（`region.json`）★60組以下の国だけ |
| ③ | 棚に、この人はこの1曲だけ | 棚の曲数 |
| ④ | 棚に40年代は10組 | 棚の年代の人数 |
| ⑤ | “ソウル”の線から | どの言葉からこの人に行き当たったか |

- **案内人（AI）は1文字も書いていない。0円・待ち時間0。作り話ゼロ。**
- **4枚に同じ種類は1回まで。**同じ文言が2枚並ぶのは「わかってない」の見本。
- **言うことが無い札には何も書かない。**水で薄めない（線も消えて、高さだけ残る）。
- **札は下に伸びない。**1行で切る（`nowrap`＋`…`）。空でも高さを取るので、
  あとから「うちの一文」が届いても**札の位置が動かない**（押す瞬間にずれない）。

### 声のほうは、刷ってあることを繰り返さない
案内人には「札にはもう刷ってある。**そこに無いほう**＝なぜ“あなたに”それなのかを言え」と入れた。
二度手間は失格、と明文で書いてある。

## 2. 珍しさに「産地」を足した ― たまごさんの例そのもの

> 「こんなシベリアのグループなんて珍しいじゃん」

これまで数えていたのは**曲数と年代だけ**だったので、冒険札がいつも古い曲になっていた。
`region.json` を数えて、**どこの人かでも珍しさを数える**ようにした。

★**分母を必ず付ける。**産地が分かっているのは 2,475組のうち **1,297組**。
だから「棚にロシアは1組だけ」とは言わせない。言わせるのはこの形：

> 産地の分かっている1,297組のうち、ロシアは1組だけ

- 札のほうには**数を書かない**（短い1行に分母が入らない）。書くのは「ロシアの棚から」まで。
- 大きい国では何も言わない（日本553・アメリカ321・イギリス125）。
  **「日本の棚から」は誰に出しても当たる＝水道水。**60組以下の国だけドアになる。

### 年代のしきい値を 300 → 120 に下げた
60年代は276組いる。それを「276組**だけ**」と言うのは嘘。
120以下で残るのは 50年代102組・40年代10組。ここなら「だけ」と言ってよい。

### ★産地のデータの間違いを2つ見つけて直した（`tools/_966_build_region.py`）

| 誰 | 何が起きていたか | 直し方 |
|---|---|---|
| Tony! Toni! Toné! | 概要は「**アメリカ・オークランド**出身のR&Bトリオ」なのに、**ニュージーランド**が付いていた。オークランドは2つある（Oakland＝カリフォルニア／Auckland＝NZ）。日本語ではどちらも同じ音 | 見分けの付かない語は使わない。`nz` から「オークランド出身」を外し、代わりに「アメリカ・◯◯出身」という**形**で拾う |
| Simon & Garfunkel | 概要が**人名「シモン」の語源の記事**になっていて、本文のシモン・ボリバルのせいで**ベネズエラ**が付いていた | 「〜に由来する名前」「この名を冠する」等が頭にある概要からは国を取らない（空欄のまま） |

**副産物：**この直しで、産地が取れていなかった9組（Leon Bridges・Skid Row・Ratt ほか）が
正しくアメリカになった。當山ひとみ（「アメリカ・沖縄育ちの**日本の**歌手」）が
アメリカにされかけたので、**「アメリカ・」だけでは決めない。「出身」までを1つの形として見る。**

## 3. 一番下の「こちらもどうぞ」を、その人ごとに

これまで誰が来ても `他を見せて ↻` の一枚看板だった。
押したか／1枚も押さなかったかは**すでに持っている**（`KYAKU`）。持っているなら使う。

| その人の様子 | ボタンの言葉 |
|---|---|
| 何か押した | `「（押した曲名）」の隣を　↻` |
| 4枚出して1枚も押していない | `いまのは忘れて、別の線で　↻` |
| まだ何も出していない | `他を見せて　↻` |
| 在庫切れ | `この棚は、ここまで` |

お願いではなく構造。AIを1回も呼ばないので0円・待ち時間0。丸い1行のまま（2行に折らない）。

## ★できていないこと（推測で埋めていない）

**「最近入荷したなかでも面白いのがありますよ」は、まだ言わせていない。**

理由：**棚のデータに入荷日が1つも入っていない。**
`head.json` が持っているのは id／名前／別名／年代／概要／ジャンル／曲数だけ。
`head.json` 自体も 2026-09-19 に1回作られたきりで、そのあと入荷した
友川カズキ10曲・特撮3曲・akiko1曲は**まだ棚に入っていない**（`status/nyuka/done/` にはある）。

裏の取れない「最近入った」を言わせるのは関所違反なので、**言わせない**ままにした。

**言えるようにするために要るもの（次の人へ）：**

1. `tools/_953_build_song_index.py` に、`status/nyuka/done/*.json` の `at`（入荷日時）を
   曲ごとに焼き込む。入荷票には日付も出典も全部入っている。
2. `head.json` を作り直す。いま2026-09-19版のままなので、入荷した14曲がそもそも棚に無い。
3. そのあと `share/check/431-seihon.html` の `mezuraList()` に
   「30日以内に入った組」を足せば、案内人は日付という裏を持って「最近入りました」と言える。
