# 関所：アーティストページに別人の曲を入れない（2026-09-19）

事故：ジャズシンガー **akiko** の棚に **矢野顕子（AKIKO YANO）** の
「Rydeen」「ラーメンたべたい」が入っていた。同じ指摘は2回目。手で消すのではなく仕組みで落とす。

---

## 1. 今どうやって紐づけていたか

`src/lib/coverGuide.ts` の `artists[].songs[]` に曲を直接ぶら下げる形で、
**描画は名前一致ではない**（棚に入っている曲がそのまま出る）。
事故は**仕入れのときに起きている**：アーティスト名で動画を検索して、出てきたものを
そのまま本人の `songs` に追記していた。

証拠：akiko の棚の末尾は `note: ""`・`year` なし・`originalRef` なしの塊で、
`小野貓 (PROD. JNYBeatz)` `Coffee or tea (Prod. SILVERSTRIKE)` `TEXT ME` など
**別の「Akiko」名義の曲**が混ざっている。名前で引いただけの跡。

## 2. 関門をどこに置いたか

- **サイト側リポジトリの `.githooks/pre-commit`** — `src/lib/coverGuide.ts` を触るコミットは
  全部通る。誰が・どのセッションが触っても効く。人が見張らなくていい場所。
- **スキル `sekisho-artist-song`** — 曲を仕入れる会話で必ず読まれる。掟と実行コマンド入り。
- 実体：`tools/sekisho/gate_artist_song.py`（37,804曲を16秒で点検）

判定は3つ。例外はカバーだけ（`originalRef` があるか「カバー」と明示があるもの）。

| | 判定 | 扱い |
|---|---|---|
| A | 曲名に「自分の名前を含む別人のフルネーム」（akiko の棚に `AKIKO YANO`） | 落とす |
| B | 曲名の演者位置に別アーティスト名が丸ごと入っている | 保留＝載せない |
| C | note も year も originalRef も無い ＋ 名前が他人と衝突する棚 | 保留＝載せない |

同じ人の棚違い（`山下達郎` と `山下達郎 (AOR/LP)`、`Celine Dion` と `Céline Dion`、
`Michael Jackson` と `Michael Jackson / The Jackson 5`）は別人扱いしない。

**関所が生きている証拠**：事故をそのまま再現した見本 `tools/sekisho/fixture_akiko.ts` を
食わせると exit 1 で止まり、Rydeen とラーメンたべたいの2曲を名指しで落とす。
正しいカバー（ルパン三世のテーマ feat. akiko、originalRef 付き）は通す。

## 3. 同じ事故が何件見つかって、何件直したか

手元にある最新のデータ（2026-09-18 02:41 のスナップショット、**2,700棚 / 37,804曲**）を全部点検した。

- **関門A（確定の別人混入）：0件**
- **関門B（共演か別人か要確認）：711件**
- **関門C（出所不明＋名前が衝突する棚）：1,519件**
- **同表記の罠（名前が名前の一部になる組）：389組**

罠の例：`akiko ⊂ Akiko Yano` / `aiko ⊂ Jhené Aiko` / `ZARD ⊂ King Gizzard & the Lizard Wizard` /
`ozaki ⊂ Ami Ozaki` / `shiba ⊂ Jun Shibata` / `asmi ⊂ Jorja Smith`

**直した件数：0件。** 外していない。理由は下の「保留」に書く。
akiko の棚は保留C 10件（`小野貓` `Coffee or tea` `TEXT ME` ほか）。

## 4. 判定できずに保留にしたもの

- **本番の coverGuide.ts はこの端末に無い。** ここにあるのは 9/18 02:41 のスナップショットで、
  そこにはまだ矢野顕子の2曲は入っていない（＝事故はそれ以降に本番へ入った）。
  ブラウザ禁止・Devinのon-demand残高に触れない条件のため、本番への書き込みは行わず、
  **「あとはコピーしてpushするだけ」の状態にして止めた** → `status/_947_sekisho_artist/`
- 保留B 711件・保留C 1,519件は**自動では外していない**。関門は「載せない側に倒す」ための
  一覧であって、既存を一括削除すると本人の曲まで巻き込む。`remove_foreign_songs.py` は
  **消さずに外して控え（.moved.json）に残す**作りにしてある。
