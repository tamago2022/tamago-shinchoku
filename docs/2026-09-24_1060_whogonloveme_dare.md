## 答え

**渋谷すばるの曲ではない。** `NEED` という**別のアーティスト**の曲。

その動画の説明文には権利表記がそのまま入る。実測（2026-09-24 05:23・YouTube Data API v3
`videos?part=snippet&id=abnMDC-sFy8`・0円／使ったユニット1・1日枠10000）:

→ **アーティスト名は `NEED`。** 作詞・作曲・編曲も `NEED`。配給は MUSIC&NEW。
　 リリースは **2026-07-11**。

出典：`status/_1060/whogon_video.json`（APIの生の返り）／`status/_1060/whogon_channel.json`

## なぜ渋谷すばるの棚に入りかけたか

渋谷すばるの2ndアルバムの**題名が『NEED』**（2020-11-11）。
チャンネル名 `NEED - Topic` の `NEED` と、**アルバム名の文字が一致しただけ**で繋がれた。
アルバム『NEED』の収録曲に「Who gon' love me」は**無い**
（1049番が公式ディスコグラフィーで確認済み・`docs/2026-09-24_1049_出典がまだ取れていない.md`）。
さらにリリースが **2026-07-11＝アルバムの6年後**なので、時系列でも別物。

## 扱い

- **棚に入れない。** `NEED` の棚は無いし、作るには材料が足りない
  （チャンネルは登録者15人・動画40本。本人のサイトもレーベルの紹介も取れていない）。
- 1049番が題名から断定を外した処置（`NEED「Who gon' love me」（YouTubeのTopicチャンネル）`）は**正しい。**
  今回それが**推測ではなく権利表記で裏打ちされた**ので、ここに残す。
- 出典：**取れた**（YouTube Data API の権利表記。一次情報）。

## 次に同じことが起きない形

Topicチャンネルの動画は、**説明文の `· <アーティスト名>` の行が名乗りの正本**。
チャンネル名（`◯◯ - Topic`）は名乗りではない。
仕入れで Topic チャンネルの動画を拾ったら、`videos?part=snippet` を1回叩いて
説明文の `Provided to YouTube by` 以下を出典として残す（0円・1本1ユニット）。
