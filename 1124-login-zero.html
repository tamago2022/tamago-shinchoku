ログインを頼まない形にする

セッション（ブラウザのログイン）は切れる。鍵（トークン）に置き換えたぶんだけ、頼まれる回数が減る。／2026-09-24 実測ぶん＋出典つき

訂正：Spotify の refresh_token は「失効しない」ではありません。
公式ドキュメント（2026年時点）に「Developer Dashboard に登録したアプリの refresh_token の寿命は6か月」と明記されています。
＝ログインはゼロにはできません。「毎日」を「6か月に1回」にするのが到達点です。

3. Spotify をこの形にする手順（たまごさんが押すのは1回だけ）

  1. Spotify にログイン（今開いているタブ）。
  2. Developer Dashboard でアプリを登録し、Client ID / Client Secret と Redirect URI http://127.0.0.1:8788/spotify/callback を設定。（中継所のポートに相乗り。新しい常駐は増やさない）
  3. こちらが同意画面のURLを作って開く。たまごさんは「同意する」を1回押すだけ。
  4. 返ってきた code を refresh_token に交換して api_keys.env に保存し、鍵台帳に行を足す。
  5. 以後は自動更新。次にたまごさんが触るのは6か月後の1回だけ。

スコープは最低これ：playlist-read-private playlist-read-collaborative user-library-read。足りないと「動いているのに何も取れていない」赤になる。
