## 決めたこと（迷った所）
- **Mac では描かない。** 試しに 2コマ（40%・4サンプル）を nice 19 で回したが、13分たっても1コマも出ず（メモリ 32GB が満杯・CPU 3.8%・場の組み立てだけで 400秒）。止めて、指示どおり GitHub Actions 20台へ。試し描き（5〜6コマ・50%）は約5分、全コマは 75%・8サンプルで回した。
- **めり込み検査（kensa）は v3 の結果をそのまま使う**（`kensa.json` を写した）。道・板・岩の形は v3 と同じで、変えたのは材質と月・霧だけ。検査を回すと chunk 0 が1時間以上延びるので省いた。
- **月の高さは Displace（縁の起伏）＋バンプ**。4 px/度の ldem_4 で十分（画面上の月は 100px 程度）。
- **写真の法線マップは使わない。** UV の無い形（岩・塔・島）に箱投影で貼るので、接線空間の法線マップは向きが合わない。代わりに写真の明るさ（あれば高さ地図）をバンプにした。
- **壁の色は写真そのままだと茶色く明るすぎた**（1回目の試し描き）。暗さ 0.55・青灰の tint・縦の濡れ筋で、濡れた玄武岩へ寄せた（2回目）。
- **遠くの山は1回目は真っ黒な円錐**だった。月明かりの基本色を上げ、凹凸を強く、前からの月光 1.8→4.5、山と空の間に薄い霞の層を足した（2回目）。
- **雲海は2回目でも雪原に見えた**（1120コマ目）。うねりを 1.6→3.0、上に漂う霧を 1.6m→3.6m・濃さ 0.12→0.22 にして本番へ。

## 次に直すこと（80点へあと10点・この便の続きで）
1. **後半の浮き島の雪帽子をやめる**：薄紫の丸い帽子を、島の上面に苔の写真（Moss002）＋うっすら霜の白にする（玩具感の一番の原因・2点）。
2. **山の輪郭を崩す**：円錐に大小2段の Displace（aerial_rocks の高さ地図を使う）を掛けて稜線をギザギザに。遠くの2つの山も同様（2点）。
3. **真上から見た雲海（543〜600コマ）**：雲の面に写真の濃淡（ambientCG の Clouds 系が無ければ Poly Haven の空 HDRI の下側を平面に貼る）を Base Color へ薄く混ぜ、起伏と別に模様を出す（2点）。
4. **飛んでいるうんこを見失わない**：800〜1000コマのカメラをもう1割寄せる（`michi_v3.py` の `c_close` 寄せ）か、うんこの Emission を飛行中だけ 1.3 倍（2点）。
5. **霧の白 0.5秒（543〜555コマ）の後の最初の1秒**：雲海の上に出た瞬間だけ月光を 1.5 倍にして「空に出た」を体で分からせる（1点）。
6. 余裕があれば：オーロラをもう少し手前にも1枚（薄く・PE.y+120）置いて、543〜1110コマでも端に少し映るようにする（1点）。
描き直しは後半 760 コマだけ（75%・8サンプル・GitHub Actions 約77分）＋組み立て 25分。前半の `frames_gh`（1〜542）と最新の `frames_gh_d`（543〜1302）は次の便のために残してある（`frames_gh_b`・`frames_gh_c`・`gh_test*` は消した）。
