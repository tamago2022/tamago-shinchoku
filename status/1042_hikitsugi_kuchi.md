## 2. 直しの中身（1点だけ）

```js
// 前
var want = Math.min(1, lv * 1.95);                       // 音の大きさだけ＝あ も い も同じ開き
var wantW = (fresh && VIS[vis]) ? (1+(VIS[vis][0]-1)*0.55) : 1;   // よこはばだけ55%薄めて混ぜる

// 後
var v6   = (fresh && VIS[vis]) ? VIS[vis] : VIS.viseme_sil;       // 母音5＋閉じ＝6形
var gate = analyser ? Math.min(1, lv*2.6) : pulse;                // 音は「鳴っているか」の栓だけ
var want  = v6[1] * Math.max(0.35, Math.min(1, gate*1.25));       // ★たてはば＝母音
var wantW = v6[0];                                                // ★よこはばは薄めない
```

足したもの（配線のみ）
- `viseme()` が `viseme_sil` を受け取るようにした。前は捨てていた＝**閉じが来ても閉じなかった。**
- `kanaToViseme()`：ま行・ば行・ぱ行の直前に `viseme_PP`（唇を閉じる）を挟む。実測 5/5 で入る。
- `pulse()`：声が無いとき（見本・比較）に同じ口を台本で動かすため。通信も課金も無い。
- `stand(el, {kuchi:"mae"})`：**比較ページだけが渡す**前の式。本番は渡さない＝必ず直した式で動く。
