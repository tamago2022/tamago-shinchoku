Spotify：たまごさんが押すのはここだけ

これを1回やれば、Spotifyのログインは二度と要りません。
（refresh_token 方式。access_token は1時間で切れますが、こちらで自動で作り直します）

1

アプリを作る（1回だけ）

Spotifyのアプリ作成を開く

画面に入れる値は、この3つだけです。

App name　たまご　（何でもよい）

Redirect URI　↓これをそのまま貼る（1文字も変えない）

http://127.0.0.1:41999/callback

Which API/SDKs are you planning to use?　Web API にチェック

→ Save を押すと Client ID が出ます。Client secret は要りません（見なくていい）。

2

出てきた Client ID をここに貼る

↓Macのターミナルに、この1行を貼って実行してください。

（上に Client ID を貼ると、ここに出ます）

実行すると 押すURLが1本出ます。それを押して「同意する」。そこで終わりです。

3

あとはこちらでやります

同意が取れた時点で、下は全部こちらが走らせます。たまごさんの出番はありません。

python3 tools/spotify_ninshou.py --tameshi   # 通ったか確かめるだけ
python3 tools/spotify_tsuika.py --shirabe    # 調べるだけ。1曲も足さない
python3 tools/spotify_tsuika.py --ireru      # プレイリスト「AI　作曲」に足す
python3 tools/spotify_tsuika.py --modoshi    # 足した分だけ1コマンドで戻す

足す候補は grok調べ　the motel.md の10曲。ダブりは入れません （プレイリストの中身をAPIで全件取り直してから突き合わせます）。

Client ID はブラウザから外に出ません（この画面は文字をつなげているだけで、どこにも送っていません）。
PKCE方式なので Client secret はこちらに渡りません。パスワードも一度も預かりません。
