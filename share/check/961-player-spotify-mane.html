なぜ途切れないのか（Spotifyと同じ形）

Spotifyのウェブ版は、曲を鳴らす部品が「ページの中」ではなく「ページの外側」に置いてあります。画面の中身だけを差し替え、鳴らす部品には一切触らない。だから曲は切れない。ここでやっているのも同じで、鳴らしている <audio> は #stage（＝ページの中身）の外にいて、ページを移っても作り直されません。

ごきげん補給所も同じ形になっています。src/routes/__root.tsx の中で、ページの中身（<Outlet />）より外側に <MiniPlayer /> と <AudioEngine /> が置いてある。つまり土台はもうできています。

画面を消しても流れる条件（ここを外すと必ず止まる）

  • 音は <audio> 要素で鳴らす。Web Audio API（AudioContext）で鳴らすと、iPhoneは画面を消した瞬間に止めます。鳴っている <audio> だけが、バックグラウンドでも音の権利を持ち続けます。
  • その <audio> をページ遷移で消さない。消した瞬間に音の権利も消えます。
  • ロック画面の表示は Media Session API で渡す。navigator.mediaSession.metadata に曲名・アーティスト・アルバム・アートワークを入れ、setActionHandler で再生／一時停止／前の曲／次の曲／シークを受け取ります。渡さないと「ブラウザ」としか出ません。

YouTubeの規約は、本当に壁か（条文で確認した）

壁です。推測ではなく、YouTube API サービスの規約にそのまま書いてあります。

YouTube API Services - Developer Policies
  I. Additional Prohibitions
  「You and your API Clients must not ... 9. create, include, or promote features
   that play content, including audio or video components, from a background player,
   meaning a player that is not displayed in the page, tab, or screen that the user is viewing」
  出典 https://developers.google.com/youtube/terms/developer-policies

YouTube API Services - Required Minimum Functionality
  「Embedded players must have a viewport that is at least 200px by 200px.」
  「You must not display overlays, frames, or other visual elements in front of
   any part of a YouTube embedded player, including player controls.」
  出典 https://developers.google.com/youtube/terms/required-minimum-functionality

読み方はこうです。

  • 画面を消して流し続ける＝禁止。「ユーザーが見ている画面に表示されていないプレイヤー」で鳴らすな、と名指しで書いてある。YouTubeの曲でこれをやる道は、規約上ありません。
  • ページを移っても切れない＝禁止されていない。プレイヤーが画面に見えたまま残るなら条文に触れません。ただし見えている枠は小さくできず、上に何かを重ねることもできません（上の2つ目の引用）。つまりYouTubeのまま残せるのは「そこそこ大きい、何も被せない、見えている小窓」までです。

だから、代わりの道を3つ

  1. 自前の音源を持つ（これが本命）。権利の取れている音／自分たちで録った音を <audio> で鳴らす。画面オフもロック画面表示も、規約の壁なしで全部できます。ごきげん補給所には AudioEngine（自前音源の常駐オーディオ）がもう入っているので、足りないのは音源と、下に書いた Media Session の配線だけです。
  2. 再生そのものは Spotify / Apple Music に渡す。曲ごとに各サービスへ飛ばす。ネイティブアプリがバックグラウンド再生を担当するので、画面を消しても流れ、LINEの返信もできます。ごきげん補給所は「探す場所・選ぶ場所」に徹する。規約違反ゼロ、作る量も一番少ない。
  3. YouTubeの曲は「見えている小窓」までで諦める。ページを移っても切れない小窓は合法なので、そこまでは実装する。画面オフのときは音を止め、ロック画面には出さない。YouTube枠は規約どおり小さくせず、上に何も重ねない。

3つを混ぜられます。曲ごとに「自前音源あり／Spotifyへ渡す／YouTube小窓まで」の3種類を持たせ、自前音源のある曲だけ画面オフで流す、という形が現実的です。

ごきげん補給所に足す配線（そのまま貼れる形）

ロック画面に曲名・絵・再生ボタンを出す部分です。AudioEngine の <audio> に対して1回呼ぶだけ。

// src/lib/mediaSession.ts
export type NowPlaying = { title: string; artist: string; album?: string; artwork?: string };

export function attachMediaSession(
  audio: HTMLAudioElement,
  track: NowPlaying,
  handlers: { next?: () => void; prev?: () => void } = {},
) {
  if (!("mediaSession" in navigator)) return;
  const ms = navigator.mediaSession;

  ms.metadata = new MediaMetadata({
    title: track.title,
    artist: track.artist,
    album: track.album ?? "ごきげん補給所",
    artwork: track.artwork
      ? [96, 128, 192, 256, 384, 512].map((s) => ({
          src: track.artwork!, sizes: `${s}x${s}`, type: "image/png",
        }))
      : [],
  });

  const set = (a: MediaSessionAction, fn: (() => void) | null) => {
    try { ms.setActionHandler(a, fn as never); } catch { /* 端末が対応していない動作は黙って無視 */ }
  };
  set("play",  () => { void audio.play(); });
  set("pause", () => audio.pause());
  set("stop",  () => { audio.pause(); audio.currentTime = 0; });
  set("seekbackward", () => { audio.currentTime = Math.max(0, audio.currentTime - 10); });
  set("seekforward",  () => { audio.currentTime = Math.min(audio.duration || 0, audio.currentTime + 10); });
  set("seekto", (d: any) => { if (typeof d?.seekTime === "number") audio.currentTime = d.seekTime; });
  set("previoustrack", handlers.prev ?? null);
  set("nexttrack",     handlers.next ?? null);

  const sync = () => {
    ms.playbackState = audio.paused ? "paused" : "playing";
    if (Number.isFinite(audio.duration) && audio.duration > 0 && "setPositionState" in ms) {
      try {
        ms.setPositionState({
          duration: audio.duration,
          playbackRate: audio.playbackRate,
          position: Math.min(audio.currentTime, audio.duration),
        });
      } catch { /* 値が揃わない瞬間は無視 */ }
    }
  };
  audio.addEventListener("play", sync);
  audio.addEventListener("pause", sync);
  audio.addEventListener("timeupdate", sync);
  audio.addEventListener("loadedmetadata", sync);
  sync();
}

やってはいけないこと：ページ遷移で <audio> を作り直す／src を空にする／AudioContext で鳴らし直す。どれも画面オフで止まります。
