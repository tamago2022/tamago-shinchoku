#98268 1145番：生成時刻だけのcommitを止める修正

2026-11-14 実装・main合流・本番(GitHub Pages)反映まで実測確認
動画棚卸し(1145番)が、内容が同じでも『最終生成』の時刻だけ変わる度にmainへcommitしていた問題（直近4日間32件中20件・63%が空振り）を修正。tools/1145_push_hidden.pyに時刻行を無視した内容比較を追加した。実測: status/public/gh390_1145_timestamp_fix.json の jissoku 配列(commit SHA4件・時刻つき)。

② 数字

32件中20件(63%)修正前・4日間の空振りcommitの割合(画面サイズではなくcommit件数の比率)
True修正ロジックの再現テスト：過去の空振り実例(12:30と15:31のペア)を正しく「同一」と判定
False修正後初めての実運用(21:32)：内容に実差分があったため正しくcommit(誤ってスキップしなかった)

実測: 以下は実際に git log で取得した commit 時刻と、時刻行を無視した内容比較(Python re で再現)の生の結果。

12:30の版 と 15:31の版 の内容比較(時刻行を無視) → True（同一・空振りだった実例）
15:31の版 と 18:39の版 の内容比較(時刻行を無視) → False（差分あり）
18:39の版 と 21:32の版(修正後の初回実行) の内容比較(時刻行を無視) → False（差分あり・正当に反映）
32件中20件(63%) = 本便より前の報告時点の実測値（直近4日間の反映32回をこの比較で
  全件判定した既報の数字）。本便ではその前後4回（12:30/15:31/18:39/21:32）だけを個別に再実測した。
