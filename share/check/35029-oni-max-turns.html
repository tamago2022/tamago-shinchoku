#35029 35029号: 鬼監督supervisorの再投入ターン数を12→25へ

2026-10-16 実装・main合流・本番(GitHub Pages)反映まで実測確認
oni-heartbeat.mjs（鬼監督v1の再投入係）がClaude CLIを呼ぶとき、--max-turns 12しか渡していなかった。実装+テスト+Git差分を残すには足りず、retry_pendingを繰り返すだけで完走しないまま1ヶ月以上放置されていた（判定日赤）。8→20〜30程度で試して調整の指示どおり、既定値を25へ引き上げ、TAMAGO_SUPERVISOR_MAX_TURNS環境変数で上書きできるようにした。

② 数字

12→25--max-turnsの既定値
a711899反映コミット(short sha)

③ 変更差分（scripts/ai/oni-heartbeat.mjs）

直前（1ヶ月以上放置されていた状態）： 
const run = spawnSync("claude", ["-p", prompt, "--max-turns", "12"], {
直した後： 
const maxTurns = Number(process.env.TAMAGO_SUPERVISOR_MAX_TURNS || 25);
const run = spawnSync("claude", ["-p", prompt, "--max-turns", String(maxTurns)], {
