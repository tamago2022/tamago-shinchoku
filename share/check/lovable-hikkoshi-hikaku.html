補給所の作りの事実
  • 中身は TanStack Start（サーバーで画面を組み立てる型）。静的ファイルだけの置き場（GitHub Pages など）では動かない。Lovable の設定では Cloudflare 向けにビルドされている。
  • DB・Edge Functions・ストレージ・鍵（秘密の設定値）は Lovable Cloud にある。Supabase の箱だが、持ち主は Lovable 側。たまごさんの Supabase アカウントは空（0件）＝「自分の Supabase」ではない。
  • 音声機能などが Cloud の Edge Function を呼んでいる（工場の道具に呼び出し先の記録あり）。

Q2. ほかのプロジェクトは開けなくなる？

開ける。消えない。Free でもワークスペース内だけの非公開プロジェクトが持て、プロジェクト数の上限も無い［2］［7］。公開中の2件（焼き芋・Cosmic Poo）は DB を使っていないので、Cloud の枠の心配も無い。

Q3. DB・サーバーの処理（Cloud）はどうなる？

  • 消えない。下げるだけでは Cloud は削除されない。削除されるのは「Cloud を外す（Remove Cloud）」を押した時だけで、これは取り消し不可［1］。絶対に押さない。
  • Free にも Cloud の毎月の枠がある：Cloud 20クレジット／月、AI 4クレジット／月（ワークスペース全体で共有・毎月1日リセット）。「一時的な提供」と但し書きあり［4］［8］。
  • 枠を使い切ると：サイト自体は表示され続けるが、DB を使う機能と AI 機能が止まる（クレジットを足すまで）［8］。
  • 見ているだけのサイトは、それだけではクレジットを使わない。使うのは DB・Edge Function・AI が動いた分［8］。
  • まだ分からないこと：補給所が今、月に何クレジットの Cloud を使っているか（コネクタからは読めなかった）。Workspace settings → Plans & credit usage → Usage details（Run credits）で見られる［8］。20を大きく下回っていればA案で問題ない。

おすすめ：A案（月0円）

補給所は独自ドメインを使っていない。lovable.app での公開と GitHub 連携は無料プランでもそのまま使える。お金を払っている理由（独自ドメイン・印を消す・AIクレジット）を、今は何も使っていない。B・Cは「印を消す」ためだけに URL が変わり、壊れる危険が増える。割に合わない。
下げる前の3つ（たまごさん本人の操作は②の確認と③のボタンだけ）
  1. DB の控えを取る：プロジェクト → More → Cloud → Overview → Advanced settings の書き出し（24時間に1回・保険）［9］。
  2. Cloud の使用量を見る：Workspace settings → Plans & credit usage → Usage details。月20クレジットを超えていたら、A案のまま「足りない月だけ買い足す」か、C案を検討。
  3. Workspace settings → Plans & credit usage → Manage → Downgrade to free［1］。「Remove Cloud」は押さない。
下げた翌日：補給所を開き、曲ページ・検索・音声が動くかを工場の巡回で確かめる。
