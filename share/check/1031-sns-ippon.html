4. ★出す道は2本あります

A｜スマホのInstagramアプリから、手で出す（鍵は要りません・2分）

  1. 1. 絵をスマホに移すMacの wae_autopost/images/07_候補_桜背景の龍_色は赤でなくピンク紫_要確認.jpg をAirDropでスマホへ。
  2. 2. 上の「この文面を丸ごとコピー」を押す英語と日本語とハッシュタグが、まとめて1回でコピーされます。
  3. 3. Instagramアプリで投稿する絵を選んで、キャプションに貼り付け。
  4. 4. 共同投稿に@wae0815を招待するInstagramの公式ヘルプに共同投稿のページがあります： help.instagram.com/5861247717337470。 ★画面の手順そのものは、こちらからは開けませんでした（中身がJavaScriptで出るページで、文字が取れません）。だから手順は書いていません。 招待を出すと、わえさんのスマホに「承認しますか」が届きます。
★この道が今日いちばん速いです。鍵を作る画面を1枚も開かずに、今日じゅうに1本が本当に外に出ます。 出たら、そのURLをこちらに貼ってください。「出た」をURLで確かめるところまでが完了です。

B｜鍵を1本貼って、以後ずっと自動にする（押すだけの並び）

  1. 1. Meta開発者登録developers.facebook.com → 右上「スタート」。 今使っているFacebookでそのまま。新しいアカウントは作りません。
  2. 2. アプリを作るdevelopers.facebook.com/apps/create → ユースケース「Instagramアカウントの管理」／アプリ名 wae-autopost／ビジネスポートフォリオ TeamTadanowae。
  3. 3. トークンをもらうdevelopers.facebook.com/tools/explorer → アプリで wae-autopost を選ぶ →「ページアクセストークン → TeamTadanowae」→ 権限4つ（instagram_basic / instagram_content_publish / pages_read_engagement / pages_manage_posts）→「アクセストークンを生成」。
  4. 4. 無期限にするdevelopers.facebook.com/tools/debug/accesstoken に貼って「アクセストークンを延長」。
  5. 5. 貼るMacの wae_autopost/1_鍵を貼る.command をダブルクリックして、貼ってEnter。打ち込むものは他にありません。
  6. 6. ★OKを出すwae_autopost/0_この11本にOKを出す.command をダブルクリック。 11本が全部出るので、見てから y を1回。これを押すまでは、鍵があっても1本も出ません（第5節）。
★1〜5はこちらでは代行できません。パスワードを打つ画面が必ず入るためです（憲法第5条）。 画面を開くところまでは全部リンクにしてあります。押すだけです。 費用は0円です（コンテンツ公開APIは無料・24時間100投稿まで）。

5. ★関所を作りました（今日の工事・実際に効くところまで確かめました）

いちばん怖いのは「鍵が入った日から、見せずに勝手に出はじめる」ことです。そうならない作りに変えました。
★OKが出ていない文面は、鍵があっても、時間が来ても、外に出ません。 post.py の投稿の一本道の上に関所を置いたので、思い出したときだけ守る約束ではなく、通らないと出られません。
★関所を開けるのは、たまごさんが 0_この11本にOKを出す.command をダブルクリックしたときだけです。 押すと11本の文面と絵が全部出て、最後に1回だけ「出していいですか」と聞きます。 y を押した11本だけが status/sns_gate/approved.json に入り、以後その11本だけが9:00と19:00に1本ずつ出ます。 OKを取り消したいときは、そのファイルを消すだけです。
★本当に止まるか、今日その場で走らせて確かめました。 OKが無い状態で投稿を走らせる → 「関所で止めました」で終了（終了コード5）。1バイトも外に出ません。 OKを入れてから同じものを走らせる → 関所は通って、その次の「鍵がない」で止まりました。＝関所は素通りしていません。
  • 朝9時と夜19時の2回だけ出すwae_autopost/queue.json の slots_jst は ["09:00","19:00"]。たまごさんの型のままです。 常駐の仕掛け（launchd）は 3_毎日9時と19時に出す_ON.command を押した時点で入ります。
  • リンクは自分のサイトへ11本とも「link in profile（プロフィールのリンクから）」で、YouTubeへの直リンクは1本もありません。 ★ただし、プロフィールに入っているリンクの中身は、こちらからは見えません。自分のサイトになっているか、1回だけ見てください。
  • 出たら記録するstatus/dispatch_outbox.jsonl に1行残して、進捗表に出します。
  • 相互フォロー営業・いいね回りはしません1件も入れていません。
