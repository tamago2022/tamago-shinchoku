確認項目結果
カメラが完全固定か特徴点マッチングで数値測定。修正前は横23px(1.8%)ズレ・1.4%ズーム(単調増加=往復なし)。ffmpeg tripodスタビライズで横7px(0.5%)・ズーム1.0%まで圧縮、目視でほぼ一致
もやが一方向に流れ続けるか(戻らないか)オプティカルフロー解析：136コマ中116コマで右方向の動き、左方向の動きは0コマ
ループ向きの絵になっているかスタビライズ後の最初と最後のフレームがほぼ同一構図(上のbefore/after画像参照)
ダッシュボードのSubtotal前後差を1円まで確定できたかブラウザ操作ツールなし＋Billing APIは403(admin権限が必要)で不可、計算値のみ。たまごさん本人にしかできない1点(下記)が必要
実費が1円まで確定できなかった理由：fal.ai公式Billing API(GET https://api.fal.ai/v1/account/billing、fal.ai/docs/platform-apis/v1/account/billingに実在)を正しいエンドポイントまで特定して呼び出したが『This API key is not permitted to perform this action』(403)で拒否された。ドキュメント上もこの系のAPIはadmin API keyが必要と明記されている。現在の~/.fal_keyは動画生成専用の通常キーでadmin権限が無い。レスポンスヘッダーにx-fal-billable-units=71.24という値はあったが、USDへ換算する単価(unit_price)を取得する手段が同じ理由で無く、根拠のない換算をして『実費』と書くことはしていない。ブラウザ操作ツールもこのセッションには搭載されていない。この2つが揃わない限り、AI側だけでダッシュボード実測を再現する方法は無い。次に進めるなら、fal.ai管理画面(https://fal.ai/dashboard/keys)でadmin scope付きのキーを追加発行いただくのが一番早い。
