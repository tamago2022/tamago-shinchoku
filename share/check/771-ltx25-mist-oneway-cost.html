★2026-09-12差し戻し対応：「最初と最後のフレームで岩・太陽・人物の位置が一致」という前回の報告は誤りだった。特徴点マッチングで数値測定したところ、実際は横に23px(画面幅の1.8%)ずれ、1.4%ズームインしていた(単調に増加＝ゆっくり前進、往復ではない)。追加のfal課金をせず、生成済みの動画1本(750番と同じくfalへの新規リクエストは無し)にffmpeg(vidstabのtripodモード＝最初のコマへ機械的に固定)を後処理として適用し、横ズレを23px→7px(0.5%)、ズームを1.4%→1.0%まで圧縮した。目視でも下のbefore/after画像の通りほぼ一致する。fal.aiダッシュボードの前後差での実費確定は、公式Billing APIを見つけて叩いたが権限不足(403)、ブラウザ操作の手段も無いため今回も取得できず、計算値のみ据え置き。
★2026-11-26差し戻し対応（2回目）：admin key(~/.fal_admin_key)を再度叩き直したところ401(Invalid API key)＝キー自体が無効と判明（403=権限不足ではなく、もっと手前で拒否されている）。一方、fal公式ドキュメント(fal.ai/docs/platform-apis/v1/models/pricing)を読み直し、通常キー(~/.fal_key)でも`/v1/models/pricing`は200で読めることを新たに発見した。実測：GET https://api.fal.ai/v1/models/pricing?endpoint_id=lightricks/ltx-2.5/image-to-video/fast → {"unit_price":0.01,"unit":"units","currency":"USD"}。これは公式APIが返す現在の単価そのもので、早見表に書いた推定単価ではない。これと、本番生成時にレスポンスヘッダーで確認済みのx-fal-billable-units=71.24を掛けると71.24 × $0.01 = $0.7124（約106.9円・150円/ドル）になる。これは下の「$0.0548(8.2円)」という旧計算値（採用したffmpeg後処理と同じく750/771番で出した最初の推定）の約13倍で、旧計算値の単価の仮定（秒数ベース）が誤っていた可能性が高い。ただし71.24という値が本当にこの5.48秒の生成1本に対応するログは本セッションでは見つけられず、確認ページのfooter記載を根拠にしている点は変わらない。実際に請求されたcost_total（1円単位の実費そのもの）を返す`/v1/models/billing-events`・`/v1/models/usage`は通常キーで403（権限不足）、admin keyは401（無効）で今回も取得できなかった——必要な権限は`billing:usage:read`で、fal.ai公式ドキュメントによりキー作成時のPermission presetで「READONLY」または「BILLING」を選ぶことが必要と判明（以前は「admin権限」としか書けなかったが、今回で正確な名称が分かった）。

ダッシュボードのSubtotal前後差を1円まで確定できたか通常キーは`/v1/models/pricing`のみ200(単価は読めた)、`/v1/models/usage`・`/v1/models/billing-events`(実費明細)は403(権限不足)。admin keyは401(無効)で不可。計算値($0.7124)のみ。たまごさん本人にしかできない1点(下記)が必要
実費が1円まで確定できなかった理由（2026-11-26再確認）：fal.ai公式ドキュメント(fal.ai/docs/documentation/model-apis/authentication/key-based)により、実費明細(cost_total)を返す`/v1/models/billing-events`・`/v1/models/usage`に必要な権限は`billing:usage:read`で、キー作成時のPermission presetで「READONLY」または「BILLING」を選んだキーが必要と判明（以前は「admin権限」という曖昧な言い方しかできなかった）。通常キー(~/.fal_key、Permission preset「API」)でこの2本を叩くと403「This API key is not permitted to perform this action」。一方、既にあるadmin key(~/.fal_admin_key)を叩くと401「Invalid API key or malformed Authorization header」＝キー自体が無効（403ではなく401なので、権限不足ではなくキーが失効・作成時のミス等で機能していない）。新たに見つけた`/v1/models/pricing`は通常キーでも200で読め、ltx-2.5/image-to-video/fastの公式単価$0.01/unitを取得できたが、これは「単価」であり「実際にいくら請求されたか」の確定ではない。レスポンスヘッダーのx-fal-billable-units=71.24(2026-09-12記録)と組み合わせると$0.7124(106.9円)という計算値になるが、これも計算値であり実費そのものではない。ブラウザ操作ツールもこのセッションには搭載されていない。この3回目の試行でも同じ結論に達したため、これ以上AI側だけでは繰り返さない。

たまごさんにしかできない1点：https://fal.ai/dashboard/keys を開いて、Create key → Permission presetで「READONLY」(推奨・読み取り専用)または「BILLING」を選んで新しいキーを発行し、値を ~/.fal_admin_key に書き込んでください（ファイルに直接追記・値はこちらには見せなくて大丈夫です）。これで以後は`/v1/models/billing-events`から1円単位の実費を自動で取得できるようになります。もし鍵発行が難しければ、代わりに一度だけ https://fal.ai/dashboard/usage-billing を開いてSubtotalの数字を教えていただければ、今回の1本分だけその場で確定できます。
