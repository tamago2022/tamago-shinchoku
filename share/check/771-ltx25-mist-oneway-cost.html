#771 ltx-2.5 fastで海辺1本だけ生成・実費の確定を試した記録

2026-09-12 実装・main合流・本番(GitHub Pages)反映まで実測確認
751番と同じ元絵(海辺のZENうんこ)を使い、ltx-2.5 fastで『もやが一方向に流れ続け、カメラは完全固定、最初と最後がほぼ同じ絵になる』動画を1本だけ生成した。fal.aiダッシュボードの前後差での実費確定は、公式Billing APIを見つけて叩いたが権限不足(403)、ブラウザ操作の手段も無いため今回も取得できなかった。代わりに公称単価からの計算値と、その計算に使った公式ドキュメントの引用を載せている。

⑤ 何をどう確かめたか

確認項目結果
カメラが完全固定か最初と最後のフレームで岩・太陽・人物の位置が一致
もやが一方向に流れ続けるか(戻らないか)9コマ抜き出しで確認、大きく右へ行って左へ戻るような往復は見えない
ループ向きの絵になっているか最初と最後のフレームがほぼ同一構図
ダッシュボードのSubtotal前後差を1円まで確定できたかブラウザ操作ツールなし＋Billing APIは403(admin権限が必要)で不可、計算値のみ
実費が1円まで確定できなかった理由：fal.ai公式Billing API(GET https://api.fal.ai/v1/account/billing、fal.ai/docs/platform-apis/v1/account/billingに実在)を正しいエンドポイントまで特定して呼び出したが『This API key is not permitted to perform this action』(403)で拒否された。ドキュメント上もこの系のAPIはadmin API keyが必要と明記されている。現在の~/.fal_keyは動画生成専用の通常キーでadmin権限が無い。レスポンスヘッダーにx-fal-billable-units=71.24という値はあったが、USDへ換算する単価(unit_price)を取得する手段が同じ理由で無く、根拠のない換算をして『実費』と書くことはしていない。ブラウザ操作ツールもこのセッションには搭載されていない。この2つが揃わない限り、AI側だけでダッシュボード実測を再現する方法は無い。
