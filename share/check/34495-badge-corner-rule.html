#34495 バッジ・アイコン・オーバーレイは小さく隅配置(標準ルール化)

2026-10-20 実装・main合流・本番(GitHub Pages)反映まで実測確認
今後どのバッジ・アイコン・オーバーレイ要素を作る際も、サムネイル短辺に対して十分小さく四隅へ配置する原則を、担当外でも適用対象の憲法としてCLAUDE.md本体(main合流済み・commit bb3080812)へ格上げした。

CLAUDE.mdへ追加されたセクション(本文そのまま)
## バッジ・アイコン・オーバーレイはサムネイルに対して小さく・隅に配置する(憲法・店主指示 2026-08-05、2026-10-20に全セッション必読へ格上げ)

店主の言葉(原文):「小さいサムネイルカードの上に乗せるバッジ/マーク類は、大きく中央配置にしない。小さいサイズでカード隅に控えめに置くのが普通の作法。」

担当領域に関わらず全セッションに適用する。この憲法だけは担当外でも適用対象。サムネイル・カードの上に新しく乗せるバッジ・アイコン・オーバーレイ要素(再生時間表示・NEWラベル・推し度マーク等も含む)は、今後すべてこの原則で作る。

- サムネイルの短辺に対して小さく・四隅に控えめ配置。中央寄り・大きい配置は禁止。
- 絶対px指定だけで大きさを決めない。必ず「カード/親要素に対する比率」で決める。
- 具体的な比率の数字はsrc/lib/designRules.tsのDESIGN_RULES.badgeが唯一の正本(短辺比率28%・隅余白6.5%)。
- 本番で実際に描画された大きさをCIが実測検査する(scripts/design-rules-check.mjs・npm run check:design-rules・検査専用ページ/design-check)。
- 本番URL1件単位の実測はnpm run check:badge-ratio -- URL(tools/oni_kantoku_badge_ratio.mjs)。
実装(badgeKinds.tsのBADGE_IMAGE_STYLE=CSSコンテナクエリmin(28cqw,28cqh))は既存コードのimportチェーンで確認済み(旧固定pxクラスBADGE_SIZE_CLASS等は使用箇所0件)。マニュアル02の古い『既知の未解決債務』記述も、この事実に合わせて同コミットで訂正済み。
