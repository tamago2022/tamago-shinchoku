#34819 外出先からの指示出し（Remote Control）：本人ログイン待ち

2026-10-09 実装・main合流・本番(GitHub Pages)反映まで実測確認
前回の確認ページに、たまごさんが開けない非公開リポジトリ（joy-relief-station）へのリンクが残っていたため、全て削除し、実際に開ける公開リンクへ差し替えました。原因そのものは変わらず：Remote Control「卵商店街」は実装済みで起動も試みていますが、現在のログイン方式（推論専用トークン）では動かせない仕組みになっています。実際のログは下の通りです。
Error: Remote Control requires a full-scope login token. Long-lived tokens (from `claude setup-token` or CLAUDE_CODE_OAUTH_TOKEN) are limited to inference-only for security reasons. Run `claude auth login` to use Remote Control.
解決には、たまごさんのMac実機で claude auth login（パスワード・二段階認証を含む本人ログイン）を1回実行する必要があります。AIエージェントのサンドボックスからはこの認証を代行する手段がありません（パスワード入力は本人しかできない操作のため、鍵の憲法どおり本人へお願いする側に回します）。
