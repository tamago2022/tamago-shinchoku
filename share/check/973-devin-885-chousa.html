③ 言えること／言えないこと

言えること。$8.85 が減ったのは 9/18 07:35 〜 9/20 17:44 のあいだで、 そのあいだに走ったのは上の8本だけ。境目をまたいだセッションは1本もない。 だから この8本以外に消えた先は無いと言えます。
もう1つ。9/18 07:35 の時点で auto-reload は OFF で、9/20 の残高は $-0.26＝マイナスのまま。 勝手に足されてはいません。
言えないこと。8本のうちどれがいくらかは取れません。 日ごとの内訳も、1本あたりの単価も同じです。理由は1つだけ — Devinが金額の口を閉じていて、画面の数字も合計しか出ないから。
「たぶんこの長い1本が重い」といった言い方もしません。裏が取れていません。

ここで無理に割り算をしないのが今回の趣旨です。530分を$8.85で割れば1分あたりの数字は作れますが、 その数字には「含まれている枠を使い切ったのがどこか」が入っていません。作った瞬間に、 たまごさんが後から検算できない数字になります。

④ 次に、この金額を見えるようにするには

  • Devinのサポートに consumption API を開けてもらう。403の文言が 「Contact support to enable the consumption API」＝向こうが開ければ取れると言っています。 開けば日付で取れるようになり、この調べもの自体が要らなくなります。
  • それが通るまでは、画面の数字を1日1回だけ書き留めるのが唯一の道です。 合計しか出ない数字でも、毎日取れば「いつ増えたか」は日単位まで絞れます。
  • 画面を機械で読めるようにするなら、Chromeの [表示] > [デベロッパー] > [Apple Events からの JavaScript を許可] を1回オンにするだけで、 Macの側から読めるようになります。
