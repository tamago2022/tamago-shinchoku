## 6. ワクワクするアイデア3つ
1. **「沈める寺」の構成に乗せる**：はじめは水に沈んだ地下階（白黒）→グミが跳ねるたびに小さく色が戻る→曲の大和音の頂点でグミが一番高く跳ね、5層の吹き抜け全体が一瞬だけフルカラーの賑わいに→また白黒の2150年へ。最後、色が残っているのはグミだけ→ケツロゴ。
2. **止まった機械が一瞬だけ動く**：波紋が当たった瞬間だけ、止まったエスカレーターが流れ、乾いた噴水が上がり、天井のモビールが回る（Blender側で動かすので本物の動き）。光が消えると止まる。
3. **人は顔のない光の残像**：よみがえる人々は長時間露光のような光のブレだけ（顔なし・AI臭さと棒人間を避ける）。音も、波紋の0.5秒だけ遠いざわめき（自作のノイズ合成）が重なって消える。

文字（ギャップ）：太く1行「2150」／細く2行目「跳ねるたびに、100年前が戻る」。
ロゴ：最後のケツロゴだけ、サングラスのコンシェルジュ（joy-relief-station `src/assets/egg-concierge-rocker.png`・v3.1/v4と同じ）。卵のロゴは使わない。
グミ：ちよさん（ちおさん）の絵・形は使わない。形＝v1 のソフトクリーム型のうず（自作 NURBS）、肌＝v4 のプロシージャル銀河（画像なし）。

1. 動きと音：当たり表は曲の構造そのもの（S2 の p は小さな跳ね、S5 の ff で一番大きく上がる、S6 は水中のようにゆっくり沈む、S7 は噴水の底で止まる）。カメラは 2 か所のホバー（吹き抜けの見上げ・天窓の下から見下ろす）で溜める。
2. 舞台：一目でモールと分かる要素を全部入れた（吹き抜け・各階の手すり・シャッターとショーウィンドウ・看板の残骸・案内板・フードコートの椅子・止まった苔のエスカレーター・天窓・噴水跡）。カメラは進む・上がる・降りるだけ（向きの速さ上限 45度/秒＝v3.1 の 80 より穏やか、傾き 5度）。
3. ロゴ：たまごさんの実物（Drive の SNS/TikTok投稿用/動画テスト・引き継ぎ/jrs_logo_endcard.png）。joy-relief-station の素材は使っていない。

### 正直な弱点（参照作との比較 `hikaku_1_mall.png`・`hikaku_2_roof.png`）
- 質感が「プロシージャルのノイズ」止まり。Maarten Hof の廃墟モールのような写真由来の PBR テクスチャ（タイル・コンクリート・錆・苔の実物感）が無く、日なたの壁は平らに見える。
- 植物が「葉の三角形の塊」。本物の葉のカード（アルファ付き）・草の密度に負けている。
- 光が EEVEE の直接光＋AO だけで、焼き込んだ間接光（GI）が無い。光の筋は体積の霧で出しているが、参照作ほどの奥行きの霞は出ていない。
- FLUX の静止画（店内の板）は **fal の残高切れ（403 User is locked: Exhausted balance）で作れなかった**（課金なし・帳簿に記録）。
- 自己採点は末尾の kiroku を参照（たまごさんの目は工場より20点辛い前提）。
