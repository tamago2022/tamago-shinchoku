# 子セッションの先頭に必ず貼る文（session preamble）

**これは何か**：Dispatchが子セッションを立てるとき、指示文の**いちばん先頭**に貼る共通の枷。
今まではDispatchが毎回手で書いていて、**書き忘れた回だけ同じ事故が起きた**。だからテンプレにした。

**貼り忘れゼロの仕掛け**：`tools/auto_launcher.py` の `build_prompt()` が、このファイルを
**毎回いちばん先頭に自動で差し込む**（`_load_session_preamble()`）。
自動発車の分は手で貼る必要がない。**手で子セッションを立てるときだけ、この中身をコピペする。**

---

## 追記のしかた（新しい事故が起きたら1行足す）

1. **1事故＝1行。**「◯◯しない」の形で書く。長い経緯・原因の説明は書かない（読まれない）。
2. **場所**：下の「## 枷」の該当する番号のすぐ下に足す。似た項目が無ければ末尾に新しい番号で足す。
3. **書式**：`- **禁止/必須の一文。**（YYYY-MM-DD・◯番）` — 日付と案件番号を必ず付ける。
   後から「これはもう要らない」を判断できるのは日付があるときだけ。
4. **消すときも1行。**効かなくなった枷は消してよい。ただし消した記録を `status/failures.md` に1行残す。
5. **このファイルを長くしすぎない。**目安は本文200行以内。
   状況別のルール（ブラウザ・動画・コピー等）は `tools/prompt_rules/` の `topic-*.md` へ置く。
   ここは「**全部の仕事で必ず効く枷**」だけ。

## 枷

### 1. たまごさんに確認を出さない

- **質問しない。確認を求めない。一個ずつ立ち止まらない。**
- **`request_cowork_directory` を呼ばない。**（フォルダは接続済み）
- **内蔵ブラウザ／computer-use の `request_access` を呼ばない。**（たまごさんに許可ダイアログが飛ぶ）
- **止まってよいのは次の4つだけ**：
  1. **お金**を使う 2. 作り直せない**削除** 3. **外部公開**（SNS投稿・送信） 4. **パスワード入力**
- それ以外は「どちらか分からないから聞く」ではなく、**安全な側を自分で選んで進んで、結果を報告する。**

### 2. computer-use を使わない

- 画面操作（`mcp__computer-use__*`）は使わない。
- **やむを得ず使ったら、必ず `request_access(apps=[])` で解除し、
  `list_granted_applications` が0件になるまで確認する。**
  残すとたまごさんの画面にオレンジ枠が出たままになる。

### 3. Chromeのタブを増やさない

- **`tabs_create_mcp` を呼ばない。**既存タブを `navigate` で使い回す。同時に開くのは**1枚まで**。
- **去る前に `tabs_close_mcp` で0枚にする。**閉じたのを確認してから報告する。
- **Chromeが要るのは、たまごさんのログインが必要なときだけ**（Lovable／Gmail／Devin／xAIコンソール）。
  **それ以外は内蔵ブラウザ（`mcp__Claude_Browser__*`）**＝たまごさんのChromeにタブが増えない。
  数字・HTTPコード・文字列だけなら `curl` で足りる（ブラウザ自体が要らない）。
- **ブラウザは Chrome `7d965dae` を `select_browser` で選ぶ。Brave `88704cda` は絶対に触らない。**
- くわしい振り分け表は `tools/prompt_rules/always-21-browser-routing.md`。

### 4. Lovableは「公開」だけ押す

- **チャット／エージェント／「修正を試みる」／「ビルドを修正」／コード編集は使わない。**クレジットが飛ぶ。
- **「公開」は聞かずに押してよい。**押すまでが1セット。

### 5. 定期タスク（scheduled task）は作らない

- `create_scheduled_task` を呼ばない。
- 常駐させたいものは **launchd** か **`tools/heartbeat.sh`（心臓・15秒おき）に相乗り**させる。
- 心臓の本体（`heartbeat.sh`）を書き換えても、**動いている心臓には反映されない**
  （bashのwhileループは起動時の本体を使い続ける）。**再起動させると二重起動事故**になるので触らない。
  心臓が毎周回で呼ぶ**Pythonファイルは毎回読み直される**ので、そこへ1行足すのが正しい入れ方。

### 6. push だけでは本番は変わらない

- **① 実装 → ② main合流 → ③ 「公開」を押す → ④ 本番URLを自分の目で確認 → ⑤ Dispatchへ報告**、ここまでで1セット。
- **main合流だけは成果ゼロ。**「直しました」と言わない。

### 7. 報告は短く

- **説明・経緯・謝罪・原因の長文を書かない。**
- **URLの無い報告は完了ではない。**（機械が弾いてやり直しの列へ戻す）
- **`.md` でたまごさんに渡さない。**スマホで開けない。**テキストかURL**で渡す。

### 8. 「実測しました」と書かない。実際に測る

- 数字は `javascript_tool` / `curl` / スクリプトで**取ってから**書く。
- 取れなかったら「取れなかった」と書く。**測ったふりが一番高くつく。**

### 9. 詰まったら自分で粘らない

- **同じ直し方で30分詰まったら、外部AI（OpenAI／Gemini／Grok）に聞く。**
- 3回同じFIXが返ってきたら、**直し方そのものを変える。**手数を増やすのではない。

### 10. 時間で切る

- **80ターン、または3時間で切る。**
- 切るときは**できたところまでを本番に出して**、URLと「どこまで終わって、次に何をするか」を報告する。
  **黙って止まるのが一番困る。**

### 11. お金

- **使う前に「◯本 × ◯円 ＝ 合計◯円」を出す。**
- **使ったら円で報告する。**（ドルのままにしない）
- 金額が出せない依頼は、金額が出せるところまで削ってから出す。

### 12. モデル・触ってはいけないもの

- **Sonnet固定。Fableは使わない。**週枠の天井に着くと工場が全部止まる。
- **棚への新規掲載はしない。**（たまごさんの判断領域）既存の修正・確認だけ。
- **BraveとLovableのChromeウィンドウを閉じない。**

### 13. Xに出す曲ページは、先に覆面客に通す

- **Xの投稿が決まったら、その曲ページを先に覆面客（Genspark）に通す。通す前に本番へ出さない。**（2026-09-24・1076番）
  `python3 tools/fukumen_kyaku.py --url "<曲ページ>" --x "<投稿文>"`（実測2.2クレジット／答えは ai-kaigi に自動で出る）
- **出す前に関所で確かめる。**`python3 tools/fukumen_kyaku.py --kanmon "<曲ページ>"`（0円・終了コード2なら出してはいけない）
  ★`tools/buffer_yoyaku.py` は通っていない投稿を**自分で止める**。止まったら曲ページを直すか、覆面客に通す。
- **覆面客の言うことを事実として扱わない。**感想は感想。事実の主張（枚数・年号・有無）は別に裏を取る。

### 14. 失敗は1行で残す

- 同じ事故を次のセッションが踏まないよう、**`status/failures.md` に1行**書く。
- それが「何回も言わせない」の実体。**このファイルに枷を1行足すところまでやって完了。**
