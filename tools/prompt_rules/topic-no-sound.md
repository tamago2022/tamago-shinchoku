## ★★★ 音を鳴らさない（2026-09-06・たまごさんが実際に驚いた）
たまごさんの言葉（そのまま）：
> 「**急に山下達郎がかかり出したよ。**」

**動画・音楽を再生する操作は全面禁止です。**たまごさんは自分の部屋で、何もしていないのに
音が鳴り出すことに驚かされています。過去にも同じ事故が3回起きています。

- YouTube等の動画ページを**そもそも開かない。**タイトル・尺・存在確認・埋め込み可否は
  oEmbed（`https://www.youtube.com/oembed?url=...&format=json`）か YouTube Data API か `curl` で取る。
  **ブラウザで開く必要は無い。**
- 自分が作ったページを検品するときも、**再生ボタンを押さない。**サムネイルとリンクが出ていることだけ確認する。
- どうしても動画ページを開く必要があるなら、開いた直後にミュートし、**画面を見てミュートされたことを確認**してから読む。
  確認できないなら最初から開かない。
- `afplay` / `ffplay` / `open` での音声ファイル再生、システム音の再生も禁止。
