## ★★★★★ ブラウザの振り分け：Chromeを使わない（2026-09-18・931番）

たまごさんの言葉（そのまま）：
> 「**それを俺に閉じさせるっていうのがまず違うんだよ。発想が。仕事を増やしちゃだめだよ。
>   食い散らかして『あと片付けておいてください』って言ってるようなもんだよ。**」

実際に起きたこと：子セッションがそれぞれ Chrome に自分のタブグループを作り、
セッションが終わってもグループが孤児として残った。**他のセッションからは見えないし閉じられない**
（`tabs_context_mcp` は自分の分しか返さない）。10枚以上溜まってたまごさんのMacが重くなり、
**タイピングも音声入力もできなくなった。**

### 使うブラウザは、この表で決める。迷ったら内蔵ブラウザ。

| やること | 使うもの | なぜ |
|---|---|---|
| 公開ページの実測・HTTPコード・中の文字列 | `curl` / WebFetch | ブラウザ自体が要らない |
| 公開ページの見た目・押しても無反応の確認・JSで描かれるページ | **Claudeの内蔵ブラウザ**（`mcp__Claude_Browser__*`） | Claudeアプリの中のペイン。**たまごさんのChromeにタブが増えない** |
| ドキュメント閲覧・調べもの・検証 | **内蔵ブラウザ** | 同上 |
| **たまごさんのログインが要るもの**（Lovable・Gmail・Devin・xAIコンソール等） | Claude in Chrome | たまごさんのセッションはChromeにしか無い |

**「Chromeが要るのは、たまごさんのログインが必要なときだけ。」**
それ以外でChromeを開いたら、その時点で間違い。

### それでもChromeを使うときの3つ（例外なし）

1. **新しいタブを作らない。**`tabs_create_mcp` を呼ばない。既にあるタブを `navigate` で使い回す。
2. **同時に開くタブは1枚まで。**
3. **終わる前に必ず `tabs_close_mcp` で0枚にする。**閉じたことを確認してから報告する。

**「あとで掃除機が拾ってくれる」を前提にしない。**掃除機（`tools/chrome_tab_sweeper.py`）は
最後の保険であって、**見分けがつかないタブは安全側に倒して残す**＝拾いきれない。
