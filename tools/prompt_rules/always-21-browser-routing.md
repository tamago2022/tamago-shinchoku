>   食い散らかして『あと片付けておいてください』って言ってるようなもんだよ。**」

実際に起きたこと：子セッションがそれぞれ Chrome に自分のタブグループを作り、
セッションが終わってもグループが孤児として残った。**他のセッションからは見えないし閉じられない**
（`tabs_context_mcp` は自分の分しか返さない）。10枚以上溜まってたまごさんのMacが重くなり、
**タイピングも音声入力もできなくなった。**

### 使うブラウザは、この表で決める。迷ったら内蔵ブラウザ。

| やること | 使うもの | なぜ |
|---|---|---|
| 公開ページの実測・HTTPコード・中の文字列 | `curl` / WebFetch | ブラウザ自体が要らない |
| 公開ページの見た目・押しても無反応の確認・JSで描かれるページ | **Claudeの内蔵ブラウザ**（`mcp__Claude_Browser__*`） | Claudeアプリの中のペイン。**たまごさんのChromeにタブが増えない** |
| ドキュメント閲覧・調べもの・検証 | **内蔵ブラウザ** | 同上 |
| **たまごさんのログインが要るもの**（Lovable・Gmail・Devin・xAIコンソール等） | Claude in Chrome | たまごさんのセッションはChromeにしか無い |

**「Chromeが要るのは、たまごさんのログインが必要なときだけ。」**
それ以外でChromeを開いたら、その時点で間違い。

### それでもChromeを使うときの3つ（例外なし）

1. **新しいタブを作らない。**`tabs_create_mcp` を呼ばない。既にあるタブを `navigate` で使い回す。
2. **同時に開くタブは1枚まで。**
3. **終わる前に必ず `tabs_close_mcp` で0枚にする。**閉じたことを確認してから報告する。

**「あとで掃除機が拾ってくれる」を前提にしない。**掃除機（`tools/chrome_tab_sweeper.py`）は
最後の保険であって、**見分けがつかないタブは安全側に倒して残す**＝拾いきれない。
片付けは作った本人がやる。

### 1. Stopフックが数えていて、合わないと終了を拒否する

`tools/stop_kanmon/tab_kanmon.mjs` が、そのセッションの記録から数える。

| 数えるもの | 道具 |
|---|---|
| 開いた | `tabs_create_mcp` ／ `navigate`（**tabIdを渡さない呼び方は1枚勝手に作る**）／ `preview_start` ／ 内蔵の `tabs_create` |
| 閉じた | `tabs_close_mcp` ／ 内蔵の `tabs_close` |

**開いた数 > 閉じた数 なら exit 2＝終われない。**（3回止めても合わなければ、記録を残して通す。無限ループは作らない）
`browser_batch` の中に入れた呼び出しも数えている。**宣言ではごまかせない。本当に閉じる道具を呼ぶしかない。**

### 2. 閉じる手段は Chrome MCP（`tabs_close_mcp`）だけ

**AppleScript / `osascript` / System Events は全面禁止。**
2026-09-26、常駐から `osascript` を叩いてたまごさんの画面にmacOSの許可ダイアログ
（「"python3" が "System Events" を制御…」）を出す事故を**1日に2回**やった。
速さや便利さでは埋まらない。**ダイアログを出した時点で失格。**
（廃止した実物：`tools/1160_tab_souji.py`。復活させないこと）

### 3. 届かないものは「届かない」と書く。0枚と書くのは嘘

- `tabs_context_mcp` は**自分のタブグループの分しか返さない。**他のセッションが残したタブには届かない。
- ブラウザ全体の枚数は、TCC許可なしには数えられない。**だから数えない。「数えられていない」と書く。**
- **Braveは新しく開かない。**それで0に保つ。既にあるタブには届かない＝そう書く。
