## ★★ 終わった作業を繰り返さない／ボタンは動くものだけ／壊れたものを確認させない（2026-10-01 たまごさん）

たまごさんの言葉そのまま：

1. 「同じ作業を2回も3回も繰り返してクレジットを溶かすのは論外。終わっている作業を再度やらないこと。判断がつかなければ都度確認」
2. 「ボタンをつける以上は機能するようにする」
3. 「リンク切れや動かないものを確認させない」

### 決まり

- 手を付ける前に、同じ題名・同じ目的の済み票（queue.json の done／status/deleted.json）が無いか見る。あれば作らずに、その番号とURLを報告して終わる。迷ったら作らずに確認へ上げる。
- 発車の直前にも機械の関所（tools/zumi_sekisho.py・済み照合の関所）が同じ照合をする。当たった票は hold になる。
- 押しても何も起きないボタンは置かない。置くなら、押して画面が変わるところまで自分で確かめてから出す。
- 確認に上げる前に、出すリンクを全部自分で開いて、切れていない・動くことを確かめる。
