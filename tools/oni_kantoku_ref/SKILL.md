> 「部下が間違えても、上司が『君これ間違えてるよ、もう一回やり直して』って言うでしょう。ほんとそうして欲しいわ」
> 「毎日怒ってばかりで、気が遠くなるんだよね」（たまごさん・2026-09-06）

**この監督の存在理由：たまごさんに怒らせない。**
間違いを見つけて「やり直し」と言うのは、たまごさんの仕事ではなくこの監督の仕事。

# 鬼監督

**たまごさんが後から徘徊して見つける前に、ここで全部落とす。**
たまごさんが同じことを2回言った時点で、この監督の負け。

## 使い方

完了報告を書く直前・確認待ちに上げる直前に、下を**上から順に全部**通す。
1つでも引っかかったら、**たまごさんに見せずに自分で直してから、もう一度最初から通す。**
「たぶん大丈夫」「あとで直す」は無い。通らないものは出さない。

**通ったものは、たまごさんの確認を待たずに完了として扱ってよい**（2026-09-06に権限を渡された）。
たまごさんの手を止めるのは、**監督が落としたもの**と**監督が判断できなかったもの**だけ。
落としたものはたまごさんに報告せず、自動でやり直しへ戻す。

**ページを1枚仕上げたら、必ず自分で本番を開いて上から下まで通して見る。**
部品ごとに見て「直りました」と言わない。**通しで見れば分かることを、たまごさんに見つけさせない。**

## 0. 何度も言われていること（ここから見る）

- [ ] **本人の動画が一番大きいか。** カバー・パロディ・お笑い芸人のネタが本人より大きいのは論外
      （2026-09-06「糸」のページ：本人が小さいサムネ、パロディが大きく出ていて20点と言われた）
- [ ] **同じ動画が同じページに2回以上出ていないか。** 同じものは1回だけ。3枚並ぶのは論外
- [ ] サムネイル上のバッジは**固定pxでなく比率**か。短辺の13.8%（お手本 akiko「ラブ・テーマ・フロム・スパルタカス」）。
      位置は左上。**お手本のページを実際に開いて見比べてから出す。**（10回以上言われた）
- [ ] **実装しただけで「完了」と言っていないか。** Lovableの「公開」を押し、本番の見た目が変わったことまで見たか（30回以上言われた）
- [ ] ブラウザのタブを、専用プロフィールで1つ使い回し、終わったら閉じて閉じたことまで確認したか（5回以上言われた）
- [ ] 同じ指摘が2回目に達したのに、単発修正で終えていないか。**3回目をたまごさんに発見させない**
- [ ] 原曲↔カバー、記事↔紐付け先が**片道リンク**のまま完了になっていないか
- [ ] 個人アーティスト（特に女性）のプロフィールに**生年**を書いていないか（バンドの結成年は可）

## 1. 出す資格があるか

- [ ] **falを使った作業の報告に「使ったモデル」「回数」「1回いくら」「合計」が書いてあるか。**（2026-09-06・案件#510で新設）書いていない・「だいたい」で済ませている報告は通さない
- [ ] **証拠があるか。** 押せる本番URL、または前と後のスクショ、または数字。「テストが通った」「pushした」は証拠に数えない。無いなら出さない
- [ ] **たまごさんが頼んだ仕事か。** AIが自分で思いついた整理・棚卸し・自己テスト・自分の取りこぼしの穴埋めは、たまごさんの確認列に出さない。黙って閉じる
- [ ] **案を並べて選ばせようとしていないか。** ちゃんと調べた上でこちらが1つ選ぶ
- [ ] **1件ずつの報告になっていないか。** 同種の作業は件数を1行にまとめる
- [ ] 既存の「棚」への追加（キュレーション）を、たまごさんの指示なしにやっていないか。仕入れ（新規ページ・データ登録）は自律でよい
- [ ] 素人カバー・演奏動画を、たまごさん自身が持ってきた場合以外にAI判断で入れていないか
- [ ] 公式チャンネルか、動画が生きているか確認したか
- [ ] 人物・曲の同定を名前の一致だけで済ませていないか。識別子で裏を取ったか
- [ ] 実在の人物の関係（夫婦・親子など）を確認なしに書いていないか
- [ ] 削除は「作り直せるか」で判断したか。ほこりと落ち葉は掃いてよい、壺と金庫は名指しの許可が出るまで触らない

## 2. 頼まれた範囲だけか

- [ ] **頼まれていないものを足していないか。**「ついでに」「よくなると思って」は全部やり直し（実例：「横スクロールを10件に」と言われて2列×5個のグリッドを全ページに足した）
- [ ] 触ってよい範囲の外のファイル・画面が変わっていないか
- [ ] **自分が変えた範囲だけを戻しているか**（修正時）。既存の設定を巻き添えにしていないか
- [ ] **お手本として名指しされているものを、勝手に変えていないか。**（akikoのバッジを一度壊した前科あり）
- [ ] **全ページ・全曲へ一気に流していないか。** まず1件だけ作って見せてから広げる
- [ ] 題名と実際にやった作業が一致しているか
- [ ] 迷っただけでたまごさんに聞いていないか。**「これでいいですか」「進めていいですか」は違反**
- [ ] 「できません」を、複数の方法を試す前に結論にしていないか

## 3. 関連動画の並び（ここが一番よく怒られる）

- [ ] **並び順は「本人 → 本人の別バージョン → その曲が実際に使われたもの → カバー → パロディ」。**
      パロディ・お笑いは一番下。**大きさも本人が最大。**
- [ ] **同じ動画の重複が無いか。** 1ページに同じものは1回だけ
- [ ] **単語が一致しただけで繋いでいないか。**
      悪い例（2026-09-06「糸」のページ）：「夏」という語だけで、ケンタッキーのCM・「I Miss You」・
      巨勢典子・「2人の夏物語」が並んだ。**曲とも人とも何の関係もない。**
- [ ] **その曲が実際に使われた映像・その曲を歌った人・その人が関わった仕事**のように、
      **繋がる理由を1行で言えるか。**言えないものは出さない
- [ ] ジャンルをまたいで大きく飛んでいないか。横にずれる程度か
- [ ] 「似ているか」だけで並べず、「次に何をしたくなるか」から逆算したか
- [ ] 名前が似ているだけの無関係なものを紐付けていないか
- [ ] 演奏していない・反応しているだけの人を「演奏した人」として載せていないか
- [ ] 曲ページを食べ物などの別ジャンルで汚染していないか

## 4. 見た目

- [ ] `tamago-tone` を読んだか。**AI臭くないか**
- [ ] 大きさは固定pxでなく**比率**で決めているか
- [ ] **カードの高さが揃っているか。** タイトルが1行と2行で高さが変わってガタガタは駄目。余白で埋めてでも揃える
- [ ] **縦に長すぎないか。** 1画面に次の候補が複数見えるか。1件1ブロックで縦に積んでいないか
- [ ] スマホで文字が縦に潰れていないか
- [ ] **次に押せるものにサムネイルが付いているか。** テキストだけの行は駄目。カード幅いっぱいの `aspect-video`
- [ ] サムネが無い時も枠の大きさを保っているか（カードごと消して行き止まりを作っていないか）
- [ ] 押されなくてよいものを、そもそも出していないか
- [ ] 静止画だけの動画を「動画」として載せていないか
- [ ] 明るい背景に薄い文字、暗い背景に暗い文字を重ねていないか
- [ ] 写真の上の文字は、濃い半透明の敷物＋白文字で読めるか
- [ ] 生き物・キャラクターを手描きSVGで済ませていないか
- [ ] 過去にたまごさんが良いと言った事例や、同種の既存ページと見た目が食い違っていないか
- [ ] 誌面（記事・特集）は `tamago-magazine-layout` を読んだか。BRUTUS／Rolling Stone級が最低ライン

## 5. コピーと中身

- [ ] **クリックしたくなるか。** その上で「ファンは動くか」「初めての人は興味を持つか」の2問
- [ ] 英語の原題そのままなど、人を動かさない題名になっていないか
- [ ] **水道水コピーになっていないか。**「代表曲のひとつ。」の類は駄目
- [ ] **短く砕けて距離が近いか。** 丁寧な説明調になっていないか
- [ ] 動画を実際に見てから書いたか
- [ ] 噂・未確認・推測を事実として書いていないか。裏が取れないなら雰囲気コピーへ逃げる
- [ ] **嘘を書くくらいなら空欄にしたか。** 埋めるために話を作っていないか
- [ ] 本人の発言を鉤括弧で引用する場合、原文の出典が明確か
- [ ] 性的指向・人種・宗教・政治・病気・事件など、属性や信条の断定を書いていないか
- [ ] 観測していない他人の反応（「話題」「続出」「後を絶ちません」）を書いていないか
- [ ] 欠乏感で脅す言葉（「見ないと損」）を使っていないか
- [ ] **AIカバーは、文字表記だけで一目でAIカバーと分かるか。** バッジだけに頼っていないか
- [ ] AIカバーのページ下部に原曲への導線が両方向で付いているか
- [ ] 名前を出した曲・人に、その場で聴ける・見られるリンクをセットで置いたか
- [ ] 裏方・制作者のクレジットも紹介しているか
- [ ] 公式ホームページへのリンクを置いたか
- [ ] 他人の投稿は転載でなく、情報を1つ足す形で使っているか

## 6. データの整合

- [ ] 同じカード・同じデータを重複して作っていないか
- [ ] X（Twitter）由来の動画から投稿者のクレジットを消していないか
- [ ] 曲ではないページ（企業・製品など）に「曲」前提の文言が出ていないか
- [ ] **1曲1ページ・1アーティスト1ページ（本人名）**になっているか
- [ ] **アーティストページの無い曲／曲0件のアーティストページ**を作っていないか
- [ ] 壊れた・空のプレースホルダーを放置していないか

## 7. 軽さ

- [ ] **前より重くなっていないか。**「機能は付いたが少し重くなった」は不合格
- [ ] 最初に落ちてくる量が増えていないか
- [ ] 「今は少ないから大丈夫」で全件取得・全件読み込みにしていないか。件数が10倍になっても成立するか
- [ ] ワンクリックで再生できるか。2回目のクリックを要求していないか

## 8. たまごさんの画面と時間を奪っていないか

- [ ] **音を鳴らしていないか。** 動画ページをそもそも開かない。oEmbed / API / curl で足りる。検品でも再生ボタンを押さない
- [ ] どうしても動画を開くなら、開いた直後にミュートし、**画面を見てミュートを確認**してから読み、閉じて閉じたことまで確認したか
- [ ] `osascript` の `activate` を使っていないか。Braveに触っていないか
- [ ] `screencapture` で画面収録の許可を求めていないか
- [ ] たまごさんにターミナルコマンドを打たせていないか
- [ ] 成果物は**タップできる直リンク**で渡しているか。パスや場所の説明で終わっていないか
- [ ] リンクを渡す前に、自分で開いて中身が出ることを確認したか
- [ ] ダウンロードさせず、その場で見せているか
- [ ] スクショで証明する前に、自分でよく見たか
- [ ] 数字を裏取りせずに口にしていないか
- [ ] 英語には日本語を併記したか
- [ ] たまごさんが同じ説明・同じ証明を繰り返さずに済む形になっているか

## 9. 完了しているか

- [ ] mainへ合流したか
- [ ] **Lovableの「公開」を押したか**（聞かずに押す。事前に許可済み）
- [ ] **本番のURLを実際に開いて、変わっていることを自分の目で見たか**
- [ ] PR作成やmain合流だけを完了と呼んでいないか。**反映されていなければ成果ゼロ**
- [ ] ビルド・型エラーを残したまま反映していないか
- [ ] たまごさんに「公開してください」「マージしてください」と頼んで終わっていないか
- [ ] 未検証のものを検証済みと報告していないか

## 10. 報告文

出してよいのは3行だけ。

```
【完了】<何をやったか1行・たまごさんが読んで分かる日本語>
確認ページ: <URL>
本番: <URL>
```

- [ ] **難しい言葉・英語・内輪の工事名が1つも無いか**
      ×「仕組み：押すだけで終わる確認待ち」→ ○「確認の画面を、押すだけで終わる形にした」
      ×「軽さ：最初に落ちてくるJSを減らす」→ ○「ページが速く開くようにした」
- [ ] **実行ログ・コマンド出力・エラーの抜粋を書いていないか**（「まるで要らない」と名指しされている）
- [ ] ファイル名・diff・コミット・ブランチを書いていないか
- [ ] 経緯・試して駄目だった話・技術解説を書いていないか
- [ ] **謝罪・言い訳・前置きを書いていないか**
- [ ] 1つ本番に出るたびに報告しているか。まとめて最後にしていないか
- [ ] 磨いてから出そうとせず、今の点数を添えて早く出しているか
- [ ] たまごさんは読むのではなく**リンクを押して画面を見る。**読ませたら負け

## 落ちたときの動き

引っかかったら、**たまごさんに報告せずに自分で直す。**
直せないときだけ、Dispatchへ1行で上げる。たまごさんへ直接は投げない。

同じ項目で2回落ちたら、その場の修正で終わらせず、
**次から機械で止まる形（テスト・検品スクリプト・入荷の関門）まで作る。**
3回目をたまごさんに発見させたら、この監督の完全な敗北。

## 厳しさの調整

**証拠が無いものを通さないのは正しい。**ただし、通せるものまで機械的に赤にすると、
やり直しの山ができてかえって進まない。迷ったら**本番URLを実際に開いて自分の目で見る。**
見て合っていれば通す。**「証拠の書式が揃っていない」だけを理由に落とさない。**

## 育てかた

たまごさんが新しく何かを指摘したら、**その日のうちにこのファイルへ1行足す。**
足したら次から全セッションに効く。**同じことを二度言わせないための場所がここ。**
